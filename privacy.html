Privacy Policy

Last updated: October 28, 2026

1. Overview

rclone Lesson Sync is a personal OAuth configuration used with the open-source rclone software. It is intended for use by its owner to synchronize files between macOS, Windows, and Google Drive.

2. Google Drive Data Access

The application requests Google Drive access to read, download, upload, modify, and delete files as directed by the authorized user.

3. Data Usage

Google Drive data is accessed only to perform file synchronization and file management operations requested by the authorized user. Data is not used for advertising or user profiling.

4. Data Storage

rclone stores OAuth credentials in its local configuration on the user's computer. Files are synchronized between the user's local storage and Google Drive.

5. Data Sharing

This personal configuration does not independently transmit Google user data to external analytics, advertising, or data brokerage services. Google Drive and rclone process data as necessary to provide the requested synchronization.

6. Security

The user is responsible for protecting local OAuth credentials and maintaining the security of the computers used for synchronization.

7. Revoking Access

Google account access can be revoked through the user's Google Account security settings.

8. Changes to This Policy

This policy may be updated if the application's configuration or data handling practices change.
