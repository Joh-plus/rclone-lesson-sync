rclone Lesson Sync

Personal Google Drive File Synchronization

About This Application

rclone Lesson Sync is a personal OAuth configuration used with rclone to synchronize files between macOS, Windows, and Google Drive.

This application is intended for personal use by its owner and is not a public synchronization service.

Google Drive Access

The application uses the Google Drive API through rclone to read, create, update, and delete files as requested by the authorized user.
